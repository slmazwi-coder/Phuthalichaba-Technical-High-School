# Phuthalichaba Technical High School Website

## 🌟 Overview
This is the official website for **Phuthalichaba Technical High School**, a no-fee public technical high school located at Outspan, Ha-Sibi, Matatiele, Eastern Cape, South Africa. Our motto is **"Grow in Excellence"**.

## 📊 Key Facts
- **Location:** Outspan, Ha-Sibi, Matatiele, 4730
- **Education District:** Alfred Nzo West Education District
- **Municipality:** Elundini Local Municipality
- **Grades:** 8–12
- **Fee Status:** No-Fee Public School
- **EMIS Number:** 200501023
- **Phone:** 082 868 3439
- **Email:** 200501023@edu.ecprov.gov.za

## 🛠️ Tech Stack
- React 19 with TypeScript
- Vite for fast development and builds
- React Router v7 for navigation
- Lucide React for icons

## 🎨 Theme
- **Primary Color:** Scarlet Red (#CC1F2D)
- **Secondary Color:** Dark Navy (#1A1F3A)
- **Accent Color:** White (#FFFFFF)
- **Font:** Arial (body)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

## 📁 Project Structure
```
src/
├── components/    # React components (Navbar, Hero, About, etc.)
├── App.tsx        # Main application
├── main.tsx       # Entry point
└── index.css      # Global styles
```

## 🤖 Chatbot
The website includes "Ask Phuthalichaba" — a rule-based chatbot that answers common questions about:
- Admissions and applications
- Academic and technical subjects
- Examination preparation
- Facilities
- Contact information
